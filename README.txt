موقع: الحاجات اللي اتغيّرت
=========================
طريقة التشغيل:
1) فك ضغط ملف ZIP.
2) افتح مجلد Eman-New-Experience.
3) افتح index.html بمتصفح Chrome أو Edge.
4) اترك index.html وstyle.css وscript.js في نفس المجلد.

الموقع يعمل محليًا بدون تثبيت. اتصال الإنترنت يُستخدم فقط لتحميل الخطوط؛
إذا لم يتوفر الإنترنت سيستخدم المتصفح خطوطًا بديلة.
